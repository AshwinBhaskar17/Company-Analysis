# NBA Employee Data Analysis

## Project Overview
This project focuses on analyzing NBA employee data using Python in Google Colab. The dataset is explored and analyzed using Pandas, NumPy, and Matplotlib to understand employee distribution, age groups, and salary patterns.

## Key Analysis
- Analyzed team-wise employee distribution and percentage.
- Studied player positions and age groups.
- Identified teams and positions with the highest salary expenditure.
- Examined the relationship between age and salary.
- Created visualizations to present the findings.

## Tools Used
Python, Google Colab, Pandas, NumPy, Matplotlib.
